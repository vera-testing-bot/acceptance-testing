# Acceptance Testing Repo

A minimal Python repository used as an end-to-end acceptance testing target for the Vera AI agent system.

Vera agents implement features in this repo to verify the full ticket lifecycle works correctly (triage → implementation → tests → PR).

## About This Document

Spec files describe *what* this system does — expected behaviors and acceptance criteria. Implementation agents decide architecture, file layout, and code structure.

Markers:
* **🚧** — Planned feature, not yet implemented
* **✅** — Verified complete
